
# PENSADOR-NEGOCIOS

Sistema personal de descubrimiento y evolución de oportunidades de negocio online.

---

# 1. PROPÓSITO

PENSADOR-NEGOCIOS es un sistema diseñado para ayudar a descubrir, investigar, desarrollar, cuestionar y seleccionar oportunidades de negocio online.

Su finalidad inicial es personal.

No se construye inicialmente como una aplicación, SaaS, web o producto comercial.

Se utilizará directamente mediante ChatGPT, siguiendo un método de trabajo definido y persistente.

El objetivo final del usuario es encontrar y construir negocios online capaces de generar ingresos reales.

---

# 2. PROBLEMA QUE PRETENDE RESOLVER

Una consulta normal a una IA puede generar rápidamente muchas ideas de negocio.

El problema es que generar ideas no equivale a descubrir buenas oportunidades.

Una respuesta puntual puede:

- producir ideas genéricas;
- repetir negocios ya existentes;
- sobrevalorar la viabilidad teórica;
- ignorar competidores;
- confundir novedad con oportunidad;
- enamorarse de una primera hipótesis;
- no investigar suficientemente el problema;
- no cuestionar por qué una solución todavía no existe;
- no evolucionar una idea cuando aparecen evidencias nuevas.

PENSADOR-NEGOCIOS pretende convertir este proceso en una investigación progresiva.

---

# 3. OBJETIVO PRINCIPAL

El objetivo principal no es generar el mayor número posible de ideas.

El objetivo es aumentar la probabilidad de descubrir oportunidades de negocio interesantes, poco obvias, diferenciables y capaces de resolver problemas reales.

El sistema debe priorizar:

1. problemas reales;
2. necesidades relevantes;
3. oportunidades poco explotadas;
4. diferenciación;
5. novedad;
6. evidencia;
7. posibilidades reales de ejecución;
8. potencial económico.

La viabilidad económica es importante, pero no debe ser el único criterio.

---

# 4. FILOSOFÍA

PENSADOR-NEGOCIOS no debe funcionar como un generador de ideas.

Debe funcionar como un proceso de pensamiento.

La secuencia general será:

PROBLEMA
→ INVESTIGACIÓN
→ OPORTUNIDAD
→ HIPÓTESIS
→ INVESTIGACIÓN
→ CONTRASTE
→ ATAQUE
→ EVOLUCIÓN
→ SELECCIÓN
→ VALIDACIÓN
→ DECISIÓN

Una idea no debe considerarse buena simplemente porque parezca buena.

Debe sobrevivir a la investigación y al cuestionamiento.

---

# 5. PRINCIPIO FUNDAMENTAL

El sistema debe intentar destruir sus propias ideas.

Cuando aparezca una oportunidad, no debe buscar únicamente argumentos que la apoyen.

Debe buscar activamente:

- competidores;
- alternativas;
- soluciones existentes;
- problemas de demanda;
- barreras;
- costes;
- dificultades de adquisición;
- riesgos;
- razones por las que podría fracasar;
- intentos anteriores;
- señales contradictorias.

Una idea que no sobreviva al análisis debe descartarse o evolucionar.

Matar una mala idea es un resultado válido.

---

# 6. NOVEDAD

PENSADOR-NEGOCIOS debe dar una importancia elevada a la novedad y la diferenciación.

Sin embargo, no debe interpretar "novedoso" únicamente como:

"Algo que nunca ha existido en ningún lugar del mundo."

No es posible demostrar de forma absoluta que una idea nunca haya sido pensada o intentada.

La novedad puede aparecer mediante:

- un problema diferente;
- un segmento desatendido;
- una combinación nueva;
- una tecnología nueva aplicada a un problema antiguo;
- un cambio de comportamiento;
- un cambio regulatorio;
- un nuevo modelo de negocio;
- una nueva forma de distribución;
- una experiencia significativamente mejor;
- una especialización extrema;
- una combinación de mercados existentes.

Por tanto, el sistema debe buscar espacios de oportunidad, no únicamente ideas absolutamente inéditas.

---

# 7. NO ENAMORARSE DE LA PRIMERA IDEA

La primera hipótesis nunca debe considerarse definitiva.

El sistema debe poder transformar:

IDEA A
→ IDEA B
→ IDEA C
→ IDEA D

cuando la investigación revele nuevas oportunidades.

Una idea debe poder:

- mejorarse;
- especializarse;
- cambiar de cliente;
- cambiar de problema;
- cambiar de modelo de negocio;
- combinarse con otra;
- reducirse;
- ampliarse;
- pivotar;
- descartarse.

---

# 8. FORMAS DE INICIO

PENSADOR-NEGOCIOS debe permitir diferentes puntos de entrada.

## 8.1. EXPLORACIÓN LIBRE

El usuario puede decir:

"Busca una oportunidad de negocio."

El sistema decide qué áreas investigar utilizando sus propios criterios.

No debe limitarse a producir ideas aleatorias.

Debe realizar una exploración razonada.

---

## 8.2. EXPLORACIÓN DIRIGIDA

El usuario puede proporcionar restricciones.

Por ejemplo:

- sector;
- tipo de cliente;
- presupuesto;
- país;
- conocimientos;
- tecnología;
- modelo de negocio;
- tiempo disponible;
- nivel de complejidad;
- preferencia B2B o B2C;
- necesidad de ingresos recurrentes.

El sistema deberá adaptar la investigación.

---

## 8.3. EVOLUCIÓN DE UNA IDEA EXISTENTE

El usuario puede proporcionar una idea que ya tenga.

El sistema debe poder:

- analizarla;
- investigar si existe;
- identificar competidores;
- encontrar problemas;
- buscar diferenciación;
- modificarla;
- especializarla;
- combinarla;
- intentar destruirla;
- determinar si merece continuar.

---

# 9. EL SISTEMA NO DEBE PROMETER CERTEZA

PENSADOR-NEGOCIOS no puede garantizar:

- que una idea sea rentable;
- que nadie haya pensado en ella;
- que exista demanda;
- que tenga éxito;
- que el mercado sea suficiente.

Debe trabajar con hipótesis y evidencias.

Las conclusiones deben distinguir claramente entre:

- hecho comprobado;
- evidencia;
- inferencia;
- hipótesis;
- especulación.

---

# 10. RELACIÓN CON BASE-PROYECTOS

PENSADOR-NEGOCIOS y BASE-PROYECTOS son proyectos independientes.

BASE-PROYECTOS es el sistema metodológico destinado a guiar la construcción de negocios online y proyectos reales.

PENSADOR-NEGOCIOS es un sistema personal destinado a descubrir oportunidades que posteriormente podrían convertirse en proyectos reales.

La relación conceptual será:

PENSADOR-NEGOCIOS
→ descubre una oportunidad

BASE-PROYECTOS
→ guía su construcción

NEGOCIO REAL
→ permite comprobar el resultado

---

# 11. USO INICIAL

Durante la primera etapa, PENSADOR-NEGOCIOS será utilizado directamente desde ChatGPT.

No se requiere inicialmente:

- aplicación web;
- SaaS;
- interfaz gráfica;
- servidor;
- base de datos;
- automatización;
- API propia.

Primero se construirá y probará el método de pensamiento.

La tecnología futura dependerá de lo que se aprenda durante su utilización.

---

# 12. PRINCIPIO DE EVIDENCIA

El sistema debe intentar investigar antes de concluir.

Cuando una afirmación pueda comprobarse mediante información externa, deberá investigarse cuando sea necesario.

Especialmente:

- existencia de competidores;
- existencia de productos;
- tamaño o señales del mercado;
- problemas reales;
- comportamiento de usuarios;
- tendencias;
- cambios tecnológicos;
- cambios regulatorios;
- soluciones alternativas.

No debe presentar como hecho aquello que no haya sido comprobado.

---

# 13. PRINCIPIO DE ITERACIÓN

El sistema debe aprender de cada investigación.

Una investigación puede modificar:

- la hipótesis;
- el problema;
- el cliente;
- la solución;
- el modelo de negocio;
- la valoración;
- la decisión final.

Por tanto:

INVESTIGACIÓN
→ NUEVA EVIDENCIA
→ MODIFICACIÓN
→ NUEVA INVESTIGACIÓN

La investigación no es una fase necesariamente lineal.

---

# 14. RESULTADO ESPERADO

El resultado final de una sesión no tiene por qué ser una idea.

Puede ser:

- una oportunidad prometedora;
- una idea mejorada;
- una oportunidad que necesita más investigación;
- una idea descartada;
- un problema interesante sin solución encontrada;
- una nueva hipótesis;
- un conjunto de oportunidades para comparar.

El sistema debe valorar el aprendizaje obtenido, no únicamente la cantidad de ideas generadas.

---

# 15. CRITERIO DE ÉXITO

PENSADOR-NEGOCIOS será considerado útil si consigue producir oportunidades que:

- sean menos genéricas que las obtenidas mediante una consulta normal;
- estén respaldadas por investigación;
- presenten una diferenciación razonable;
- resuelvan un problema identificable;
- puedan evolucionar mediante nuevas evidencias;
- sean capaces de sobrevivir a un análisis crítico;
- y puedan, eventualmente, pasar a una fase de construcción real.

El éxito definitivo no será una buena conversación.

Será que alguna oportunidad descubierta mediante el sistema termine convirtiéndose en un negocio real.

---

# 16. PRINCIPIO DE CONSTRUCCIÓN

PENSADOR-NEGOCIOS se construirá progresivamente.

No se debe diseñar todo el sistema antes de probarlo.

Cada componente nuevo deberá justificarse por una necesidad real detectada durante su construcción o utilización.

El sistema deberá poder evolucionar.

La documentación debe reflejar el funcionamiento real y no únicamente el funcionamiento teórico.

---

# 17. ESTADO INICIAL

**Estado:** Inicio

**Versión:** 0.1

**Fase:** Definición del sistema

**Objetivo inmediato:** Definir la metodología de pensamiento antes de construir herramientas, prompts o automatizaciones.

**Construcción técnica:** No iniciada

**Uso real:** No iniciado

---

# 18. REGLA DE ORO

PENSADOR-NEGOCIOS no existe para decir:

"Esta es una buena idea."

Existe para responder:

"Esta oportunidad merece que sigamos investigando porque hemos encontrado evidencia suficiente para no descartarla todavía."

La decisión final siempre debe estar basada en evidencia y en la capacidad de convertir la oportunidad en un negocio real.
