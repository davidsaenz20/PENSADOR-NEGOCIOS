---

# 2. OBJETIVO DEL PROYECTO

Construir un sistema personal que permita:

- descubrir oportunidades de negocio;
- investigar problemas reales;
- detectar necesidades;
- buscar soluciones existentes;
- analizar competencia;
- detectar espacios poco explotados;
- generar hipótesis;
- evolucionar ideas;
- intentar destruirlas;
- comparar oportunidades;
- decidir cuáles merecen investigación adicional;
- y, eventualmente, seleccionar oportunidades que puedan pasar a construcción mediante BASE-PROYECTOS.

---

# 3. NATURALEZA DEL PROYECTO

PENSADOR-NEGOCIOS es inicialmente una herramienta personal.

No se está construyendo inicialmente como:

- aplicación;
- SaaS;
- web;
- producto comercial;
- API;
- programa independiente.

El sistema se utilizará directamente mediante ChatGPT.

Una posible comercialización futura solamente podrá considerarse después de demostrar que el sistema funciona para el propio usuario.

---

# 4. RELACIÓN CON BASE-PROYECTOS

Los repositorios son independientes.

BASE-PROYECTOS:

Sistema metodológico para guiar la construcción de negocios online y proyectos reales.

PENSADOR-NEGOCIOS:

Sistema personal para descubrir oportunidades que posteriormente podrían convertirse en proyectos reales.

Relación:

PENSADOR-NEGOCIOS
→ OPORTUNIDAD
→ BASE-PROYECTOS
→ CONSTRUCCIÓN
→ NEGOCIO REAL
→ VALIDACIÓN

PENSADOR-NEGOCIOS no debe modificar BASE-PROYECTOS directamente salvo que una necesidad detectada durante su construcción justifique una mejora en la BASE.

# 14. DECISIONES IMPORTANTES ACTUALES

## Decisión 1

PENSADOR-NEGOCIOS será inicialmente un proyecto independiente de BASE-PROYECTOS.

**Motivo:**

Evitar mezclar el sistema metodológico de construcción de negocios con la herramienta personal destinada a descubrir oportunidades.

---

## Decisión 2

La primera versión será utilizada directamente mediante ChatGPT.

**Motivo:**

Validar primero el método de pensamiento antes de invertir recursos en construir una aplicación o automatización.

---

## Decisión 3

El sistema tendrá tres formas principales de entrada:

1. exploración libre;
2. exploración dirigida;
3. evolución de una idea existente.

**Motivo:**

Permitir tanto descubrimiento autónomo como investigación dirigida y análisis de ideas que el usuario ya tenga.

---

## Decisión 4

La novedad será un criterio importante, pero no se exigirá demostrar que una idea nunca haya existido.

**Motivo:**

La ausencia absoluta de precedentes no puede demostrarse con certeza.

La diferenciación puede proceder de una combinación, segmento, problema, tecnología, distribución o modelo de negocio.

---

## Decisión 5

El sistema debe intentar destruir las oportunidades antes de considerarlas suficientemente buenas.

**Motivo:**

Reducir el sesgo de confirmación y evitar enamorarse de ideas iniciales.
